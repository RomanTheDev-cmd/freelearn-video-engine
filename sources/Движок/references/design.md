# Северные видеошаблоны Freelearn

Источник оформления: `/Users/roman/Library/Mobile Documents/com~apple~CloudDocs/Главная рабочая папка ИИ/Проекты/FreeLearn/Сайт/public/styles.css`, `index.html` и `app.js`, снимок 2026-10-14. Палитры в `assets/style.json` взяты из светлого `:root` и тёмного `prefers-color-scheme`. Для северного медитационного примера выбирать горные озёра, туман, породу и спокойную воду; осматривать начало/середину/конец исходного фрагмента и вертикальный кроп. Доминирующие столбы/постройки, оживлённые дороги, резкие жёлтые блики и быстрое движение отвлекают от этого оформления. При необходимости ограничить сцену полями video_offset_seconds и video_end_seconds: нужный отрезок плавно растягивается на сцену, без жёсткой петли.

Изменение сайта само по себе не перезаписывает навык: перед обновлением сверить сайт, сохранить копию и оформить новую версию.

## Темы и типографика

- `light`: фон #f3f6f7, белая карточка, текст #1b272e, акцент #2c6383.
- `dark`: фон #0e1418, карточка #151d22, текст #e9eff2, акцент #9cc4da.
- Сохранять остальные цвета из соответствующего `themes` в style.json: линии, вторичный текст, мягкий акцент и дальний горный силуэт.
- Поле сценария `"theme": "light"` или `"dark"`; `--theme` имеет приоритет. Светлая тема — по умолчанию. Один MP4 имеет одну тему: автоматической реакции на настройки устройства в видео нет.
- Сайт использует системные шрифты. В видео остаётся Inter под OFL; веса 450–500 для текста, 600 для подписи, 680 для заголовка и 700 для бренда. Не копировать проприетарный системный шрифт в распространяемый навык.

## Общие компоненты

Реализация — `scripts/visuals.py`; параметры геометрии едины для статичных кадров и движущегося видео.

1. **Окно пейзажа:** поля 5% ширины, верх 6% высоты, нижний край около 66,7%. Скругления, естественный холодный цвет без сильного затемнения. Движущееся видео видно через прозрачное округлое окно в неподвижном слое интерфейса.
2. **Виджет подсказки:** в медитации caption_mode=stage — одна короткая инструкция на весь этап, без переключения по каждой реплике; отдельная карточка ниже изображения, от 69,8% до 91,3% высоты. Небольшое название этапа и до двух строк подсказки для 16:9, до трёх для 9:16. Слова и строки проверяются по фактической ширине шрифта; длинный текст надо сократить, а не прятать обрезкой.
3. **Постоянный знак:** нижняя подпись вне картинки и виджета. Скруглённая плитка акцента, горный контур как в шапке сайта, слово Freelearn. Знак и карточка не исчезают при переходах пейзажа.
4. **Интро/аутро:** крупный бренд, «Учитесь в своём темпе», два спокойных горных силуэта. Нижние виджет и подпись присутствуют и здесь. Общее интро остаётся длительностью 1 с.
5. **Карточка урока:** крупный заголовок и, при необходимости, поле `points` со списком до трёх коротких строк. Номера — в мягких плитках акцента. Произвольный интерфейс программы этим компонентом не имитировать.

Переход растворяет один пейзаж в следующий только внутри верхнего окна; виджет и нижний логотип берутся с исходного таймлайна без наложения двойного текста. Все кодируемые фрагменты имеют единые SAR 1:1 и limited BT.709, иначе FFmpeg может перезапустить фильтры на смене источника и сбросить время. Изменение подсказки внутри одного пейзажа или карточки не запускает новый переход. Новый заголовок/список шагов карточки запускает переход верхнего окна. Full HD — 1920×1080 или 1080×1920; уменьшенный preview — отдельный технический образец.

## Проверка изменения оформления

По указанию Романа от 2026-10-15 обслуживание оформления и проверка качества сами по себе не разрешают рендер, новые видео или озвучку. Без запроса на новый визуальный/аудиообразец — чтение исходников, `check_logic.py`, синтаксис и уже существующие кадры/отчёты; изменённый путь не объявлять проверенным новым экспортом.

Только при явно запрошенном preview/видео: собрать `assets/examples/meditation-preview.json` с `--preview --voice review`, выполнить `check_video.py --preview --expected-seconds 24` и осмотреть начало, подсказки, переход и конец. Full HD — отдельный запрошенный экспорт без `--preview`. Для запрошенной проверки общих компонентов выбрать нужные тему/формат, не создавать матрицу вариантов автоматически. Статичные образцы не доказывают корректность движущегося видео или полного семиминутного рендера.

Если аудиовход недоступен или прослушивание не проводилось, прямо указать это. Стилизацию, ASR и техническую проверку не выдавать за слуховую оценку или одобрение голоса Романом.

Обзор компонентов без синтеза голоса — только если новый визуальный образец явно запрошен; эта команда создаёт новые PNG:

```sh
~/.local/share/freelearn-video/.venv/bin/python ~/.codex/skills/freelearn-video/scripts/preview_components.py --output "/path/to/review-folder"
```

Скрипт использует сохранённые примеры, создаёт 16 полноразмерных PNG и два обзорных листа. Проверять отдельно нужны и сами кадры, и закодированный MP4.

Для фотографий есть необязательный `image_crop: [left, top, right, bottom]` в долях 0–1. Если его нет, используется `preferred_crop` из реестра; исходник сохраняется. У nature-1 выбран правый участок без маленькой дальней опоры ЛЭП. Это кадрирование фотографии, оно не меняет область реального видеоисточника.

Ключ статичного компонента учитывает SHA-256 реализации visuals.py, шрифта и исходного медиа. Изменение содержимого с сохранёнными size/mtime не возвращает старый PNG. Постер видео извлекается на video_offset_seconds (по умолчанию 0), внутри допустимого диапазона, и отсутствие кадра даёт явную ошибку. Для слишком короткой практической инструкции выводится диагностическое предупреждение о чтении; intro/outro не подпадают под него. Эти программные проверки не заменяют визуальный просмотр.
