# Быстрый запуск Freelearn Video

1. Прочитайте действующий sozdanie-video и ENGINE.md. Для учебной речи выбранTera, ASR — .venv-asr, обработка — .venv-audio. Старый медитационный генератор удалён; прежние записи и права сохраняются.
2. Создайте сценарий JSON с общей длительностью, сценами, короткими репликами и постоянными подсказками. Для новой медитации ориентир — 420 секунд.
3. Короткий пробный файл:

   ```sh
   ~/.local/share/freelearn-video/.venv/bin/python ~/.claude/skills/freelearn-video/scripts/build_video.py script.json --preview --voice approved -o preview.mp4
   ```

4. Полный локальный Full HD черновик по запросу пользователя:

   ```sh
   ~/.local/share/freelearn-video/.venv/bin/python ~/.claude/skills/freelearn-video/scripts/build_video.py script.json --voice approved -o fullhd-review.mp4
   ~/.local/share/freelearn-video/.venv/bin/python ~/.claude/skills/freelearn-video/scripts/check_video.py fullhd-review.mp4 --expected-seconds 420 --ocr --full-decode
   ```

5. Сборщик сначала декодирует исходные видео и сверяет число кадров, затем проверяет длину каждого собранного фрагмента и общего видеопотока. Проверяйте кадры, титры, уровни и распознавание речи уже после сведения. Если аудио-вход недоступен, укажите, что тембр на слух не проверен; ASR не подменяет слуховую оценку.
6. Для локальной проверки слов после экспорта:

   ```sh
   ~/.local/share/freelearn-video/.venv-asr/bin/python ~/.claude/skills/freelearn-video/scripts/check_speech.py fullhd-review.mp4 --output speech-review.json
   ```

   Распознавание работает без подсказки исходным текстом. Совпадение слов не доказывает хорошую дикцию и тембр; расхождения требуют проверки. Дорожки `.mix.speech.wav`, `.mix.music.wav` и `.mix.wav`, а также `.mix.audio.json` позволяют менять и проверять баланс.

7. Прежнее принятие описывает сохранённые записи. Новые голоса не наследуют его. Новый медитационный синтез сейчас отключён; полную приёмку нового учебногоTera-экспорта проверять отдельно.

## Новая стилистика сайта

По умолчанию — светлая северная тема. Для тёмной используйте `--theme dark`, для светлой — `--theme light`; поле `"theme"` в JSON действует, если флаг не задан. Тема MP4 фиксирована и не переключается вслед за темой устройства.

Пример на 24 секунды с двумя пейзажами и короткими репликами: `assets/examples/meditation-preview.json`. Для Full HD этого короткого образца уберите `--preview`; для проверки укажите `--expected-seconds 24`. Компоненты и источник палитр описаны в `design.md`. При доработке навыка по умолчанию запускать только `scripts/check_logic.py` и проверку синтаксиса. Новые MP4 и озвучка — только по явному запросу Романа; прежний экспорт не доказывает работу изменённого кода. Если рендер запрошен, выбрать один подходящий образец, повторно используя кэш. Полный семиминутный экспорт — отдельная запрошенная проверка.

### Проверка до сборки

`check_logic.py` проверяет сценарии/таймлайны/сохранение на небольших данных, блокируя внешние процессы. Для входов и математики звука: `~/.local/share/freelearn-video/.venv-audio/bin/python ~/.claude/skills/freelearn-video/scripts/check_audio_logic.py`. Эти проверки не создают видео или озвучку и не доказывают качество нового экспорта.

При запрошенной сборке прежний комплект сохраняется в `.freelearn-cache/export-*/previous`. Обычные ошибки переноса вызывают восстановление; отключение питания посреди операции требует проверки manifest и сохранённых файлов. Отчёты сохранять отдельными `.json` вне источника навыка.

### Проверки после аудита 2026-10-20

Checker по умолчанию требует полные metadata и непустые credits/rights (SRT — если ожидается речь), сохраняет хеши MP4/кода проверки и выявляет изменение файла во время сканирования. `--legacy` — только явно обозначенная проверка старого экспорта с предупреждениями, не новая приёмка. Новые проверки не создают разрешение на видео.

Обработанный FLOAT-вход с `|sample|>1` отклоняется до эффектов и записи. Для допустимого stem `--speech-processed` сохраняет заданный gain. Кэш компонентов зависит от содержимого renderer/шрифта/медиа; постер извлекается с начала выбранного диапазона. Короткие инструкции медитации получают предупреждение о времени чтения; интро/аутро исключены. Текущий кандидат речи −30.5 LUFS, фон −29 LUFS, приглушение реплик −2 dB; это не слуховое одобрение.

Намеренно тихий preview урока без речевых интервалов и с music_enabled=false допускается с явным measurement_status=intentional_silence и предупреждением. Неизвестный вывод измерителя либо тишина при ожидаемом звуке остаются ошибкой. Это не одобрение качества звука.
